## 修订时额外消除的歧义

- 不把可变执行attempt纳入逻辑动作意图摘要，避免一次重试制造新业务动作；节点/对账的attempt级提交仍绑定attempt。
- 幂等结果过期后需要去重墓碑或可核查索引，不能删除记录后再声称能识别旧请求。
- 不可信撤销事件先拒收，不能让伪造事件触发任意业务暂停；可信来源的同步缺口只在获准范围内保守拦截。
- 事件网络重放可能返回同页，按event_id去重；不将存储无重复承诺扩张为网络恰好一次。
