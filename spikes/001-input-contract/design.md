# 验证片段设计
- Model：单份JSON包含输入JSON Schema及新鲜度要求；版本和内容摘要由批准流程绑定，不执行任意脚本。
- SourceAdapter：Excel列名/SQLite列名映射为相同业务字段，实际源文件只读。完全读取限定小批次后才通过。
- DataProvider：结构、单位、对象目录、新鲜度校验；整批拒绝，输出不可变序列化快照。
- Business：只消费标准记录和批准模型引用，无来源分支，确定性阈值示例非生产规则。
- SnapshotStore：按内容摘要命名，重复等价写幂等，损坏/不同内容拒绝；不是完整数据库。
- CLI：先通过全部校验再落快照/结果。无调度接线；与input_snapshot_ref的映射只是候选，不能注册到正式核心。
- 测试通过公有load_snapshot、evaluate和CLI；先红后绿。网络故障不在此片段，文件缺失/不可读返回结构化失败；不凭缺失值补事实。
